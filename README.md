# Cancer Prediction Using Multiplicative Calculus-Based Neural Networks

## Project Overview
This project explores the use of multiplicative calculus-inspired neural networks for breast cancer classification.

The aim is to compare a conventional neural network with a multiplicative-inspired approach.

## Objectives
- Understand conventional neural networks.
- Explore multiplicative calculus in neural networks.
- Build and train both models.
- Compare their performance.
- Evaluate using classification metrics.

## Dataset
Breast Cancer Wisconsin Dataset

- 569 samples
- 30 input features
- 2 classes: Malignant and Benign

## Technologies Used
- Python
- Google Colab
- TensorFlow
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
